# VCE English Exam Preparation Guide

A free study website for VCE Units 3/4 English (texts: *Sunset Boulevard* and
*Rainbow's End*), built by an English teacher for his Year 12 cohort at
South Oakleigh College. Live site:
**https://nmo-soc.github.io/VCE-English-Guide/**

## What it contains

Scene summaries and analyses, quote banks, film technique guides, annotated
high-scoring exemplars, essay frameworks for all three exam sections,
assessors' report takeaways (2024 and 2025), ~200 practice topics, and
interactive study tools including flashcards, quizzes, an exam generator and
an AI study assistant ("Ask Max") that answers only from the site's own pages.

## Safety and transparency

- The site is entirely static HTML/CSS/JavaScript — it contains **no
  downloads, no executables, no trackers beyond anonymous page-view counts
  (GoatCounter), and no account system**, and it sets no cookies.
- The AI assistant is proxied through a Cloudflare Worker; no API keys exist
  anywhere in this repository or on the site.
- Questions asked of the AI are logged (with network address) for service
  health, as disclosed on the chat page.
